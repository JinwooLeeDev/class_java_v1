# Java 학습 저장소 (`java_v1`)

자바 기초 문법부터 객체지향 프로그래밍, 예외 처리, 제네릭, 스레드, 날짜·시간 API와 Swing까지 공부하며 작성한 예제 코드 모음입니다.

하나의 완성된 애플리케이션보다는 주제별로 작은 예제를 직접 작성하고 실행하면서 개념을 확인하는 학습용 프로젝트입니다. 수업 예제와 개인 연습 문제, 콘솔 미니 프로그램이 함께 들어 있습니다.

## 학습 내용

- 변수, 자료형, 형 변환과 상수
- 산술·비교·논리 연산자
- 조건문과 반복문 (`if`, `for`, `while`, `break`, `continue`)
- 배열, 객체 배열과 `ArrayList`
- 메서드, 생성자와 메서드 오버로딩
- 클래스와 객체, 캡슐화, `static`, `final`
- 상속, 메서드 오버라이딩과 다형성
- 추상 클래스, 인터페이스와 `instanceof`
- 포함 관계와 객체 간 협력
- 문자열 처리 (`String`, `StringBuffer`, 텍스트 블록)
- 예외 처리와 사용자 정의 예외
- 제네릭과 제한된 제네릭
- 내부 클래스와 익명 클래스
- `Thread`, `Runnable`과 `synchronized`
- `java.time` 날짜·시간 계산과 출력 형식 지정
- Swing을 이용한 프레임, 패널, 이미지와 키보드 이벤트 연습

## 프로젝트 구조

```text
src/
├─ ch01 ~ ch08       # 자바 기본 문법과 제어문
├─ com/oop1 ~ oop20  # 객체지향 개념별 예제
├─ exercise          # 계산, ATM, 자판기, 야구 게임 등 연습 문제
├─ ex_test           # 추상 클래스·인터페이스·다형성 종합 연습
├─ my_test           # 개인 클래스 설계 연습
├─ starcraft         # 여러 버전으로 발전시키는 객체지향 예제
├─ useful            # 문자열, 예외, 제네릭, 스레드, 날짜 API 등
├─ swing             # Java Swing GUI 및 이벤트 연습
└─ review            # 학습 내용 종합 복습 코드
```

## 주요 예제

| 경로 | 내용 |
| --- | --- |
| `src/exercise` | ATM, 자판기, 카페 키오스크, 숫자 야구 등 콘솔 프로그램 |
| `src/com/oop12` | 객체 배열을 활용한 연락처·도서 관리 CRUD 연습 |
| `src/starcraft` | 상속과 인터페이스를 적용하며 단계별로 개선한 유닛 예제 |
| `src/ex_test` | 직원 급여와 음료 예제를 통한 추상화·다형성 연습 |
| `src/useful/ch04` | 예외 처리 및 사용자 정의 예외 |
| `src/useful/ch05 ~ ch07` | 제네릭과 제한된 제네릭 |
| `src/useful/ch09` | 멤버·정적·지역·익명 내부 클래스 |
| `src/useful/ch10 ~ ch11` | 스레드 생성과 공유 자원 동기화 |
| `src/useful/ch12` | `LocalDate`, `LocalDateTime`, `Period`, `Duration` 활용 |
| `src/swing` | 레이아웃, 이미지 출력, 버튼·키보드 이벤트 처리 |

예를 들어 `useful.ch12.Step6`에서는 생일의 요일, 만 나이, 경과 일수, 크리스마스 D-day와 한국어 날짜·시간 형식을 계산합니다.

## 실행 환경

- Java JDK 17 이상 권장
- IntelliJ IDEA
- 별도의 외부 라이브러리 및 빌드 도구 없음

프로젝트의 `src` 디렉터리가 소스 루트로 설정되어 있습니다.

## 실행 방법

각 예제 클래스가 독립적인 `main()` 메서드를 가지므로 실행하고 싶은 파일을 IntelliJ에서 열고 `main()` 옆의 실행 버튼을 누르면 됩니다.

터미널에서는 프로젝트 최상위 디렉터리를 기준으로 다음과 같이 실행할 수 있습니다.

```powershell
javac -encoding UTF-8 -d out src\useful\ch12\Step6.java
java -cp out useful.ch12.Step6
```

다른 예제를 실행할 때는 소스 경로와 패키지를 해당 클래스에 맞게 변경합니다.

## 참고 사항

- 학습 과정의 시행착오와 단계별 개선 내용을 남기기 위해 비슷한 이름의 예제가 여러 개 존재합니다.
- 일부 프로그램은 `Scanner` 입력을 기다리므로 IntelliJ 실행 창에서 값을 입력해야 합니다.
- Swing 예제에서 상대 경로로 이미지를 불러올 때는 실행 작업 디렉터리가 프로젝트 최상위 폴더인지 확인해야 합니다.
- 이 저장소는 학습 진행에 따라 계속 내용이 추가되거나 기존 코드가 개선될 수 있습니다.
